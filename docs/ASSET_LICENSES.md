# Asset licenses

One row per pack (D-187; supersedes one row per asset). Added when a pack is first used (IDEA.md, D-079). The pack
folder under `assets/` holds its own `LICENSE.txt`; the Files column counts non-hidden, non-`.import` files in the folder,
including `LICENSE.txt`. `tools/asset_validator.gd` checks the rows against disk.
